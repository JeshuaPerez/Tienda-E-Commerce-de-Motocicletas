# MotoStore GT

Plataforma web de comercio electrónico y gestión operativa para un concesionario de motocicletas nuevas en Guatemala: tienda virtual, punto de venta (POS), inventario por VIN, caja diaria, compras a proveedores, facturación y reportes.

- `backend/`: API REST con Node.js, Express y PostgreSQL (Prisma).
- `frontend/`: SPA con Vue 3, Vite y Tailwind CSS.

Las instrucciones de instalación se agregan al cerrar el proyecto.
